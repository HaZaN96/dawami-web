# دوامي (نسخة الويب)

هذا المستودع فيه **نسخة الويب الجاهزة** من تطبيق دوامي بس، ومنه يشتغل الرابط:
https://hazan96.github.io/dawami-web/

- الكود الأصلي في مستودع `dawami` الخاص (المجلد `app/`).
- ما فيه أي جداول دوام ولا بيانات. ملف الـ PDF ينقرأ داخل الجوال وما يطلع منه.
- للتحديث: `npx expo export --platform web` داخل `dawami/app`، وبعدها انسخ محتوى `dist/` هنا.
